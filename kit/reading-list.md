# Reading list

These are the primary sources. Quote these in a review, not a blog post.

## The four OWASP lists

- Top 10 for LLM Applications, 2026 edition (released August 2026)
  https://genai.owasp.org/resource/owasp-genai-llm-top-10-2026/
- Top 10 for Agentic Applications, 2026 edition (published December 2025)
  https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/
- Agentic Skills Top 10 (2026 edition, in development)
  https://owasp.org/www-project-agentic-skills-top-10/
- MCP Top 10 (2025 edition, beta)
  https://owasp.org/www-project-mcp-top-10/

## Worth knowing

- System prompt guidance, from the 2025 LLM list (now folded into LLM08:2026)
  https://genai.owasp.org/llmrisk/llm072025-system-prompt-leakage/
- OWASP Agent Control Standard, version 0.1: runtime enforcement for agents. Announced with the 2026 LLM list.
  https://genai.owasp.org/2026/09/01/owasp-genai-security-project-unveils-2026-top-10-for-llm-applications-new-agent-control-standard-and-sponsors-as-community-tops-30000-members/
- MITRE ATLAS: how attackers go after AI systems, technique by technique
  https://atlas.mitre.org/
