# The kit

This is the take-home kit from the governance session. Use it on your next deployment, not just on this repo.

| File | Reach for it when |
|---|---|
| owasp-cheatsheet.md | a reviewer names an OWASP item and you need to know what they mean |
| signoff-questions.md | you're getting ready for the review meeting |
| action-risk-sheet.md | you're deciding which tool calls need a human |
| controls-map.md | you're deciding where each control runs |
| deployment-pack-template.md | you're writing the pack the reviewers sign |
| example-deployment-pack.md | you want to see a finished pack (it's for this repo's agent) |
| rollback-runbook.md | before go-live, so the bad day already has steps |
| reading-list.md | you want the primary sources |

An order that works: fill in the action risk sheet first, then the controls map, then the pack.
The question bank tells you what's still missing.
